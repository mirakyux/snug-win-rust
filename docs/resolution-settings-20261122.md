# 分辨率优先的屏幕设置

用户要求不按机型配置屏幕，提供一个默认分辨率、常见预设与自定义输入。

- 新屏默认 1080×1920；横屏默认 1920×1080。
- 常见预设包含 720×1280、900×1600、1080×1920、1080×2400、1440×2560，以及横屏和平板尺寸。
- 预设、自定义和恢复默认只编辑草稿，点击“应用分辨率”才保存并生效；切换应用不会改分辨率。恢复默认按当前已应用的像素方向选择 1080×1920 或 1920×1080，不跟随尚未应用的草稿或旧机型方向字段。
- 删除主要流程中的机型选择器与机型必选条件；添加屏幕无需机型库。旧设备字段只用于配置兼容。
- 新建采用通用默认；读取旧配置时将旧公式产生的像素尺寸锁为精确值，保留现有 1080×1900 等尺寸。已有手动值原样保留。
- 启动窗口、桌面预览和设置摘要均读取配置的分辨率，不再单独调用机型公式。

复用现有每屏分辨率字段和设置控件，未增加依赖。回归覆盖预设/恢复默认不自动应用、自定义横向宽高不被归一为竖屏、无机型即可添加屏、窄屏布局及旧配置迁移。

功能改动涉及 `snug-app` 的 `settings.rs` / `main.rs` / `ui.rs` 和 `snug-core` 的 `config.rs` / `screen_fit.rs` / `screen_plan.rs`，同步 README、CHANGELOG 和验收文档。此次续接新增的代码修复集中在 `settings.rs` 与 `config.rs`；主要简化是移除主流程的机型选择及必选校验，统一复用分辨率草稿和既有应用动作。

仍受桌面应用最小窗口尺寸限制；窗口过宽时保留固定屏并提示尺寸受限，不会自动扩屏或缩小字号。本次为 v1.0.4 本地候选，未自动提交、推送或发布。

## 剩余边界

- 旧电脑屏只迁移精确像素，不能保证保留旧 DPI。例如内置“通用 2560 × 1440”横屏在旧公式下为 100%，迁移为同样物理像素后，当前物理尺寸策略可能采用 200%。手机和平板不走这一电脑分支；本轮没有增加旧 DPI 来源元数据或新的 DPI 设置。未完成旧电脑屏的真实操作验收。
- 为保持既有主屏选择，旧方向字段暂不随手动宽高改写；实际显示尺寸和布局按精确像素计算，恢复默认也按实际像素方向判断。
- 便笺等单实例应用首次启动占用串行操作队列的问题仍是独立待办，不属于此次分辨率设置收尾。
