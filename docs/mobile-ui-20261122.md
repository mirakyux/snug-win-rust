## 界面与简化

手机短边映射到统一的 400 egui 点；真实屏与桌面预览共用同一尺度，避免只在 Windows 上放大文字。
底栏按相同短边尺度预留 60 点，容纳 48 点按钮及留白。横屏取短边，不把横向宽度再次放大底栏。

- 应用 / 运行中 / 设置移到底部；移除顶部总开关、危险退出操作和重复页签。
- 单窗口直接进入，多窗口先选择；运行列表不再默认展开全部窗口。
- 新建与关闭操作集中到明确菜单，关闭窗口或关闭全部前确认，复用现有 controller 动作。
- 窄屏设置使用整页单列；子页返回设置首页，再返回应用。设备、机型、更新和高级诊断仍可达。
- 收起本次手机屏不关闭自动开屏配置，仍复用既有归位和重入胶囊流程。
- 复制气泡扩大并按工作区限位；深浅主题正文、次文字及主要操作色做对比度回归。
- 删除旧顶部布局、窗口全展开及废弃的焦点/预览缩放缓存，无新增 crate。
