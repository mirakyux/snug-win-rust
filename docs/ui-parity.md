# 界面结构对照（C# 原版实测 vs Rust 版）

以下是 2026-11-18 用 UIA 从已装的 C# v1.2.0 导出的历史控件树，用于理解原交互与定位差异。

## 2026-11-22：手机触控优先的有意偏离

用户确认主要使用场景是手机远控，v1.0.1 因此不再按桌面 C# 窗口做像素复刻。
保留真实应用、窗口动作和单窗口切屏机制，改为以下布局：

- 完整手机屏短边统一映射到 400 个 egui 点，避免 Windows DPI 把 48 点按钮缩成手机上的小目标。
- 应用 / 运行中 / 设置放在底部；搜索不主动抢焦点。网格根据可用宽度容纳 3 / 4 / 6 列，不硬撑溢出。
- 多窗口先选择，运行列表默认折叠；关闭全部窗口和单窗口关闭均需明确确认。
- 铺窗后底栏保留应用、截图、更多；打开更多或设置时恢复整屏，避免面板被底栏裁切。
- 小于 720 点的设置使用单列整页，返回先回设置首页，再回应用；大屏保留原侧栏。
- “收起手机屏”只结束本次屏并恢复窗口，不关闭自动开屏配置；重入仍复用现有胶囊。

以下 C# 几何与尺寸仅作历史参考。真实手机上的最终触区和远控缩放仍需手动验收。

## Rust 版现状与差距

| 项 | C# 原版 | Rust 版（改前） |
|---|---|---|
| 列表形态 | 竖向列表，每 App 一行 | 图标网格（`TILE=76`） |
| App 行信息 | 图标 + 名字 + 「N 个窗口」 | 只有图标 + 名字 |
| 行内操作 | `+` 新窗口、`×` 关全部窗口 | 无 |
| 窗口行 | 展开在 App 下方，可单独 `×` | 顶部另起「运行中」页，只有标题 |
| 标题 | 顶部 `App` 大字 | 顶部是机型名 + 状态 + 计数 |
| 搜索 | 单独一行搜索框 | 挤在标题行右侧 |
| 页签 | 「运行中 / 全部」两个半宽按钮 | 底部条右侧的小按钮 |
| 右上角 | `⏏` `📱` | 无（功能在底部条：手机屏勾选 / ⚙） |
